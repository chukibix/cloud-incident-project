Cloud Reliability Showcase

Live demonstration of Kubernetes autoscaling, GitOps, and system observability.

About the Project

This backend infrastructure is designed to demonstrate core Site Reliability Engineering (SRE) and DevOps principles. It features dedicated endpoints that intentionally stress the system's compute and storage layers, allowing external load-testing tools to trigger automated scaling events.

Infrastructure & Tech Stack

Kubernetes Argo CD AWS EC2 AWS RDS (PostgreSQL) Grafana Prometheus NestJS

Simulation Endpoints

Use a load-generation tool (like hey or curl) against these routes to observe the cluster's behavior in real-time:

  • /simulations/cpu - Maxes out Node.js event loop to trigger Horizontal Pod Autoscaler (HPA).
  • /simulations/database - Generates heavy IOPS and forces intensive in-memory sorting to stress the RDS instance.
  • /simulations/slow - Simulates artificial network latency to test Ingress timeouts.
  • /simulations/error - Triggers HTTP 500 errors to test alerting pipelines.
